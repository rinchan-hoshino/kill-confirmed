# Project icon

The dog-tag project icon is AI-assisted artwork, finalized through native pixel reconstruction from an original generated concept and a generated color reference. Its final shape, shading and recessed markings use a uniform 32 × 32 pixel grid with 12 opaque colors and a transparent background.

- `icon-32.png` is the native asset.
- `icon.png` is an exact 12x nearest-neighbor enlargement, centered with an 8-pixel transparent margin on a 400 x 400 canvas for project pages.

The final artwork was selected by the project owner. The project icon is separate from the in-game dog-tag item texture.
