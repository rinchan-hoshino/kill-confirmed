# Function example (Minecraft 1.21.1)

Copy `tag_stats` into `world/datapacks/`. Run `/scoreboard objectives add kc_kills dummy` once and `/reload`. Copy `kill_confirmed.toml` into `config/` and restart. New tags have the default lore plus `Kills: 7`.

For 26.x, adjust `pack.mcmeta` using the matching entry in the repository's `profiles.json`.
